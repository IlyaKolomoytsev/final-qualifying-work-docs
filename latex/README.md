# LaTeX-шаблон ВКР

Основной файл стиля находится в `latex/fqw.cls`. Он рассчитан на XeLaTeX/LuaLaTeX и централизует оформление пояснительной записки, технического задания и приложений.

## Подключение

В дальнейшем `main.tex` нужно будет перевести на класс:

```tex
\documentclass[
  numbers=continuous,
  document-code={ВКРБ-09.03.04-10.19-03-24-81}
]{../latex/fqw}
```

Для технического задания код документа должен заканчиваться на `91`, для пояснительной записки -- на `81`.

## Сборка

Из директории конкретного документа:

```bash
latexmk -r ../.latexmkrc main.tex
```

Сборка использует XeLaTeX, `biber` и отдельный каталог `build/` для служебных файлов и PDF.

## Заложенные правила

- A4, поля: слева 3 см, справа 1,5 см, сверху и снизу 2 см.
- Основной текст 14 пт, 1,5 интервала, абзацный отступ 1,25 см, выравнивание по ширине.
- Основной шрифт Times New Roman; если он не установлен, используется TeX Gyre Termes как метрически близкая замена.
- Нумерация страниц внизу по центру.
- Ссылки PDF чёрно-белые, без цветного оформления.
- Заголовки слева с абзацного отступа, без точки в конце и без принудительного начала раздела с новой страницы.
- Рисунки подписываются снизу по центру: `Рисунок 1 - Название`.
- Таблицы подписываются сверху слева: `Таблица 1 – Название`.
- Продолжение переносимой таблицы подписывается без повторения названия: `Продолжение таблицы 1`.
- Формулы нумеруются справа в круглых скобках.
- Перечисления первого уровня используют дефис.
- Приложения получают русские буквы и отдельную нумерацию рисунков, таблиц и формул.
- Библиография настраивается через `\FqwSetupBibliography{FQW.bib}` в числовом порядке первого упоминания.

## Полезные команды класса

```tex
\FqwUnnumberedSection{Введение}
\FqwUnnumberedSection{Заключение}
\FqwUnnumberedSection{Список использованных источников}

\where x -- значение параметра;\\
y -- расчётный коэффициент.

\FqwTableCaption{Основные размеры втулок}
\FqwContinuedTableCaption{1}
\FqwContinuedLongTableCaption{4}{1}

\appendix
\FqwAppendix{Техническое задание}
\FqwSubAppendix{Диаграмма вариантов использования}
```

`main.tex` для `explanatory-note` и `statement-of-work` пока не изменялись.
