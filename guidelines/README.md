# Guidelines

Этот каталог является базой знаний по требованиям кафедры к выпускной квалификационной работе и преддипломной практике.

## Быстрый вход

- [00-vkr-package.md](00-vkr-package.md) - общий состав ВКР, обязательные материалы и приложения.
- [01-poyasnitelnaya-zapiska.md](01-poyasnitelnaya-zapiska.md) - пояснительная записка: объем, структура, содержание разделов.
- [02-technical-assignment.md](02-technical-assignment.md) - техническое задание: структура ГОСТ 19.201-78 и наполнение разделов.
- [03-system-programmer-guide.md](03-system-programmer-guide.md) - руководство системного программиста: структура ГОСТ 19.503-79.
- [04-software-requirements-and-verification.md](04-software-requirements-and-verification.md) - требования к программе, апробация, верификация и передача тестировщику.
- [05-events-and-predefenses.md](05-events-and-predefenses.md) - мероприятия, предзащиты, презентации и условия допуска.
- [06-normcontrol-antiplagiat-dump.md](06-normcontrol-antiplagiat-dump.md) - нормоконтроль, антиплагиат и размещение на dump.vstu.ru.
- [07-binding-and-disk.md](07-binding-and-disk.md) - порядок прошивки работы и состав диска.
- [08-predegree-practice.md](08-predegree-practice.md) - преддипломная практика и отчет.
- [09-formatting.md](09-formatting.md) - требования к форматированию документации.
- [10-title-pages.md](10-title-pages.md) - титульные листы из приложения Б и ссылки на исходные страницы.

## Правила поддержки

- Имена файлов и директорий должны быть в kebab-case без пробелов.
- Внутренние ссылки должны быть относительными.
- При изменении структуры нужно обновлять ссылки и проверять Markdown-документы через `lychee`.
