# Преддипломная практика

Источник: [042](<sources/guidelines-for-the-2022-final-qualification-project/extracted/pages/042.txt>)-[044](<sources/guidelines-for-the-2022-final-qualification-project/extracted/pages/044.txt>).

## Цель практики

Цель преддипломной практики:

- совершенствование практических навыков работы в профессиональной области;
- выполнение этапов ВКР, связанных с тестированием разработанного ПО;
- подготовка графических материалов к защите.

## Задачи практики

Основные задачи:

- ознакомиться с концепциями и атрибутами качества ПО: надежностью, безопасностью, удобством использования;
- изучить роли людей, процессов, методов, инструментов и технологий обеспечения качества;
- получить практические навыки тестирования;
- выполнить эксперименты по проверке корректности и эффективности принятых проектных решений;
- получить практический опыт подготовки презентации;
- получить практический опыт оформления научно-технических отчетов по результатам выполненной работы.

## Способ проведения

Преддипломная практика проводится:

- на кафедре `Программное обеспечение автоматизированных систем`;
- стационарным способом;
- согласно календарному учебному графику.

Перед практикой студенту выдается индивидуальное задание. Оно публикуется в разделе `Преддипломная практика` курса `Выпускная квалификационная работа бакалавра` на `edu.vstu.ru`.

## Типовая структура отчета по практике

1. Титульный лист задания.
2. Титульный лист отчета.
3. Содержание.
4. 1. Презентация.
5. 2. Руководство системного программиста.
6. 2.1 Общие сведения о программе.
7. 2.2 Структура программы.
8. 2.3 Настройка программы.
9. 2.4 Проверка программы.
10. 2.5 Дополнительные возможности.
11. 2.6 Сообщения системному программисту.

## Наполнение разделов

Титульный лист задания и титульный лист отчета оформляются по приложению Б и материалам курса ВКР на `edu.vstu.ru`.

В содержании перечисляются основные заголовки и подзаголовки с номерами страниц.

В разделе `Презентация` размещается презентация по два слайда на странице.

В разделе `Руководство системного программиста` приводится РСП. Содержание РСП должно соответствовать разделу [03-system-programmer-guide.md](03-system-programmer-guide.md).

## Чек-лист отчета

- [ ] Есть титульный лист задания.
- [ ] Есть титульный лист отчета.
- [ ] Есть содержание с номерами страниц.
- [ ] Презентация размещена по два слайда на странице.
- [ ] В отчет включено РСП.
- [ ] РСП содержит общие сведения, структуру, настройку, проверку, дополнительные возможности и сообщения системному программисту.
